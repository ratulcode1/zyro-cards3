**Zyro Cards** is a modern, scalable platform designed for managing digital NFC and QR smart business cards. It provides a sleek, interactive, and mobile-first interface for users to share contact information, social media links, portfolio details, and business connections seamlessly.

---

## 🌟 Key Features

- 🎴 **Interactive Digital Profile**: Displays modern, customizable digital cards with direct links to WhatsApp, LinkedIn, website links, and contact saving.
- 🔐 **Admin & Account Portal**: Built-in authentication UI for user login and card management.
- 🎨 **Responsive & Sleek Design**: Modern dark/light UI optimized for all screen sizes (Mobile, Tablet, Desktop).
- 📲 **One-Click Contact Integration**: Add contact details instantly with a tap.
- ⚡ **Lightning Fast**: Built on top of React, Vite, and Tailwind CSS for optimized load times.
